外贸实战 Prompt 与工具箱

这里收录四个外贸场景的示例 Prompt。复制后请按实际产品、客户和公司政策调整，先检查保密要求，再核验 AI 输出。

价格谈判 · 筹码置换

四维筹码置换守价推演 Prompt

假设客户提出目标价 $85，并提到其他供应商报价。先核实报价是否可比，再整理交期、规格、批量与付款条件，准备回信草稿。

你现在是一名熟悉海外 B2B 销售的商务谈判助理。请将以下内容作为示例情境处理，不要自行假定客户背景或我方交付能力。 面对客户的目标价要求（例如：“Target price is [价格]，其他供应商更便宜”），请帮我整理【四维筹码置换备选方案】： 1. 列出需要核实的采购动机、报价可比性和供应链转换成本；证据不足时不要替客户下结论。 2. 筹码置换方案：如经内部核算后拟调整价格，可以讨论哪些非价格条件？ - 交付周期（具体天数须以实际排产能力为准） - 订单批量与阶梯锁价 - 技术公差与包装规格 - 付款比例与汇率锁定 3. 撰写双语邮件草稿：只使用已经核实的交期、价格和质量条件；待确认的信息以问题列出，不写成承诺。
推荐适配：具备深度思考链的大模型 (Reasoning LLMs)
长询盘 · 技术排雷

复杂长询盘条款初筛 Prompt

面对篇幅较长的 Technical Specification，可先提取测试、认证、交期与违约条款，整理需要技术和商务负责人核实的问题。

你是一名帮助整理长询盘条款的助理，不代替工程、法务或财务判断。输入前请确认资料可用于所选模型。以下括号内均为示例，请审查客户长询盘技术附件文本： 【审查目标】： 1. 找出【与我方常规产品或报价依据不同】的技术要求（如测试条件、绝缘等级、温度范围等），并标注原文位置。 2. 标出所有涉及【履约风险与违约金/罚则】的隐蔽条款（如延期交货每日0.5%违约金、空运补货责任）。 3. 检查【特殊包装、测试报告与第三方监造】要求（如SGS现场验货、熏蒸木箱标识）。 4. 输出《技术澄清清单（Clarification List）》，标注原文位置和不确定项，供我方技术及商务负责人在报价前核实。
推荐适配：长上下文推理大模型
客户跟进 · 破冰唤醒

报价后未回复的三步跟进 Prompt

报价发出后暂未收到回复？先确认对方是否收到，再根据已核实的信息安排后续跟进，避免制造虚假的紧迫感。

我上周向海外客户发送了正式商业报价，目前尚未收到回复。 请帮我制定一套【三步跟进邮件草稿】。以下时间间隔仅为示例，可按客户节奏调整： - 第一封（报价后第5天 · 简短确认）：询问报价是否收到，以及是否有需要澄清的规格或条款； - 第二封（报价后第10天 · 提供选项）：只有在内部确认可行后，才提出替代配置或交期供客户选择； - 第三封（报价后第20天 · 确认进度）：询问项目是否暂缓及合适的下次联系时间；不要编造原料涨价、库存期限或排期紧张。
适用于报价后的日常跟进
付款方式 · 财务风控

OA 远期账期风险对冲博弈 Prompt

面对 OA 60/90 天账期要求，应先核实买方信用、保险条件、融资成本和现金流。此 Prompt 用于整理待评估的谈判选项。

海外买家要求：“We only accept OA 60 days after Bill of Lading date.” 作为出口企业，我们在风险可控前提下促成合作。请为我设计【账期博弈置换策略】： 1. 列出需要核实的买方身份、信用资料及信保或银行支持条件，不假设授信已经获批。 2. 组合对冲方案： - 比较预付款、信用证、出口信保等选项的适用前提； - 如考虑远期融资，列出需要财务、银行或保险机构确认的成本与条件； 3. 输出商务回函草稿：说明付款条件仍待内部审核，不承诺未经批准的授信、保险或融资安排。
付款条件需由财务和风控复核
